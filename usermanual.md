# 📖 User Manual

Welcome to the Smart Internet Traffic Intelligence System. This manual explains how to run the system and navigate the real-time observability dashboard.

## 1. Starting the System

The entire platform is containerized. To start it, you only need Docker and Docker Compose installed on your machine.

1. Open a terminal in the root directory of the project.
2. Run the following command:
   ```bash
   docker-compose up --build
   ```
3. Wait for the services to initialize. The Spring Boot backend will connect to Redis and ClickHouse, and the React frontend will be built and served via Nginx.
4. Once the logs settle, open your web browser and navigate to: **[http://localhost:3000](http://localhost:3000)**

## 2. Navigating the Dashboard

The frontend is a single-page application built with React. The sidebar provides navigation to different intelligence views.

### Live Dashboard (Overview)
- **Top KPIs**: Displays Requests Per Second (RPS), total requests, average latency, active sessions, and active alerts.
- **RPS Chart**: A real-time area chart showing the volume of traffic over the last 60 seconds.
- **Latency & Error Rate Chart**: Tracks system performance and stability.
- **Top Endpoints**: Shows which API routes are receiving the most traffic.
- **Region Distribution**: A pie chart showing where traffic is originating from (simulated).

### Latency Heatmap
- Visualizes the latency of the last 96 request "buckets".
- **Green** indicates fast responses (<100ms), while **Red** indicates slow responses (>1000ms).
- Use this to quickly spot visual clusters of slow requests that might indicate a struggling backend service.

### Alert Center
- A dedicated view showing all alerts generated by the backend engines.
- Alerts are grouped by severity: `INFO`, `WARNING`, `CRITICAL`, and `EMERGENCY`.
- Contains detailed information including the affected endpoint, the triggering value, and the threshold.

## 3. Simulating Traffic & Attacks

The system includes a built-in traffic simulator that runs automatically in the background, generating normal web traffic.

**Triggering a Spike (DDoS Simulation)**
To see the system react to abnormal conditions:
1. Look at the left sidebar under "Controls".
2. Click **🔴 Trigger Spike**.
3. Watch the Live Dashboard. You will see the RPS skyrocket.
4. After a few seconds, the EMA-based Spike Detection Engine will fire an alert, and a `⚠ SPIKE ACTIVE` warning will appear in the top bar.
5. If you leave the spike running, it may escalate into a DDoS Suspected alert.
6. Click **✅ Stop Spike** to return traffic to normal levels. The system will automatically resolve the spike state once traffic drops back below the threshold.
